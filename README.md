# dakiquang/homebrew-tap

Homebrew formulae for my open-source tools.

```bash
brew install dakiquang/tap/claude-desktop-twins
```

| Formula | What it does |
|---|---|
| [claude-desktop-twins](https://github.com/dakiquang/claude-desktop-twins) | Run several Claude Desktop accounts side by side on macOS. Unofficial, not affiliated with Anthropic. |
